# Calculator v1.0.1 — One Calculator. Every Screen.

The app previously branded under a different name is now **Calculator** across web, desktop and mobile. This release updates the title, package identifiers, native window title, UI branding, metadata and installer names.

**Web app after the repository is renamed:** https://codewithroni.github.io/Calculator/

## Downloads
- Windows 10/11 x64: Calculator-1.0.1-Windows-Setup-x64.exe (installer) or Calculator-1.0.1-Windows-Portable-x64.exe
- macOS Apple Silicon: Calculator-1.0.1-macOS-arm64.dmg
- macOS Intel: Calculator-1.0.1-macOS-x64.dmg
- Linux Debian/Ubuntu x64: Calculator-1.0.1-Linux-amd64.deb
- Android: Calculator-Android-debug.apk (for testing); signed Calculator-Android-signed-release.apk only if release signing secrets are configured
- iOS: Simulator builds are validated; a signed Calculator-iOS-1.0.1.ipa is only produced with valid Apple Developer certificate and provisioning profile

## Notes
The desktop installers are currently unsigned and may trigger OS security prompts. The Android debug APK is intended for testing and is not a Google Play production package. An iOS .ipa cannot be distributed without Apple signing credentials.

# Nova Calc v1.0.0 — Cross-platform desktop & mobile

**Nova Calc** is a premium React calculator by CodeWithRoni with dark/light themes, keyboard controls, history, percentage, and safe arithmetic.

### Download the correct version below
- **Windows 10/11 (x64):** \`Nova-Calc-1.0.0-Windows-Setup-x64.exe\` (installer) or \`Nova-Calc-1.0.0-Windows-Portable-x64.exe\` (no installation).
- **macOS Apple Silicon:** \`Nova-Calc-1.0.0-macOS-arm64.dmg\`.
- **macOS Intel:** \`Nova-Calc-1.0.0-macOS-x64.dmg\`.
- **Linux Debian/Ubuntu (x64):** \`Nova-Calc-1.0.0-Linux-x64.deb\`.
- **Android:** \`Nova-Calc-Android-debug.apk\` for testing/sideloading. A signed release APK is only attached if signing secrets are configured.
- **iPhone/iPad:** iOS project and simulator build are supported. **An installable signed IPA is only attached if Apple Developer signing and provisioning credentials are configured.** This release does not claim unsigned IPA files are installable.
- **Web:** https://codewithroni.github.io/calculator-react/

### Notes
Desktop packages are **unsigned** unless publisher certificates are configured, so Windows SmartScreen / Apple Gatekeeper may show warnings. Android debug packages are not Play Store distribution builds. Check artifacts when the workflows complete: files appear progressively after release creation.

Source and documentation: https://github.com/CodeWithRoni/calculator-react
